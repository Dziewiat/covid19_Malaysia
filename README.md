# covid19_Malaysia

This project is an analysis of COVID pandemic in Malaysia, separated into two main parts: summary and inferential statistics.

## Summary statistics

Analysis of COVID cases, vaxinations and deaths through the years 2020-2024. Scripts for generating the plots are present in "scripts" directory, and plots in the "figures" directory.

## Inferential statistics

Prediction of future deaths caused by COVID. Scripts for generating the plots are present in "scripts/Norbert" directory and plots in the "Plots/Norbert" directory.
